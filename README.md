# Target Sistemas — Desafio técnico

Resolução, em Python, de um desafio técnico da **Target Sistemas**, desenvolvida por Willian Raphael Rosa Gomes em um notebook do Google Colab (setembro de 2024).

[![Abrir no Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/wiUl/Target_Desafio/blob/main/main/Target_Sistemas_Desafio.ipynb)

## Conteúdo

O notebook [`main/Target_Sistemas_Desafio.ipynb`](main/Target_Sistemas_Desafio.ipynb) traz a solução de 5 questões:

| Questão | O que a solução faz | Saída registrada no notebook |
| --- | --- | --- |
| 1 | Soma os números de 1 até um índice com um laço `while` (índice 13) | `91` |
| 2 | Verifica se um número pertence à sequência de Fibonacci, usando a propriedade dos quadrados perfeitos | Para 13: pertence à sequência |
| 3 | Lê um arquivo JSON de faturamento diário e calcula o menor valor, o maior valor e quantos dias ficaram acima da média (a média considera apenas os dias com faturamento maior que zero) | Sem saída registrada |
| 4 | Calcula o percentual de cada estado (SP, RJ, MG, ES e Outros) sobre o total | SP 37,53%, RJ 20,29%, MG 16,17%, ES 15,03%, Outros 10,98% |
| 5 | Inverte uma palavra e indica se ela é um palíndromo | Para "ama": palíndromo |

## Observações

- A questão 3 depende de um arquivo `dados.json` que **não está no repositório**, e o notebook não registra a execução dessa célula.
- O enunciado original do desafio não está no repositório.

## Como executar

Abra o notebook pelo botão "Abrir no Colab" acima ou carregue o arquivo no Jupyter. As questões 2 e 5 pedem entrada do usuário (`input`).
